# Historical sources

The two program directories preserve the public-domain-marked transcriptions in
[chrislgarry/Apollo-11 at e7576d5](https://github.com/chrislgarry/Apollo-11/tree/e7576d50f7c279a707cfaa71be2020592dbf43a8).
The 177 files supplied locally were checked against that revision, allowing for
line-ending conversion. The [upstream Public Domain Mark notice](../LICENSES/Apollo-11-PDM.md)
applies to the imported transcription. The root Apache-2.0 license covers original
project contributions.

| Directory | Program | Assembly listing | Corroboration |
| --- | --- | --- | --- |
| [Luminary099](../Luminary099/) | Lunar Module, Luminary 1A (LMY99 revision 001) | NASA 2021112-061, July 14, 1969 printout | [Virtual AGC Luminary catalog](https://www.ibiblio.org/apollo/Luminary.html) |
| [Comanche055](../Comanche055/) | Command Module, Comanche revision 055 (Colossus 2A) | NASA 2021113-051, April 1, 1969 printout | [Virtual AGC Colossus catalog](https://www.ibiblio.org/apollo/Colossus.html) |

The local Luminary transcription identifies itself as LMY99 revision 001.
Virtual AGC catalogs it as Luminary 099/1 and identifies it as the flown
revision. The catalog discusses conflicting historical recollections and
distinguishes the earlier 099/0 reconstruction from this listing.

Credit belongs to the Apollo guidance software teams at the MIT Instrumentation
Laboratory, the MIT Museum, Deborah Douglas, Paul Fjeld, Ron Burkey, the Virtual
AGC transcription and proofing contributors, and the maintainers of the GitHub
mirror. The program headers and indexes retain the source-specific credits.

The two program directories are a historical record. Keep experimental
variants outside those directories. A transcription correction should identify
the scan, page, and affected line and describe any effect on assembled words.

Virtual AGC is a separate upstream project. Its host tools have their own
license notices, generally GPL-2.0-or-later. The project does not redistribute
those tools.
